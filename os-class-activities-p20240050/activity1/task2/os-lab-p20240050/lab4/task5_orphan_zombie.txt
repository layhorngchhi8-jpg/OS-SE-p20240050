--- Zombie and Orphan Cleanup Notes ---
Q: How are orphans cleaned up? A: init/systemd (PID 1) adopts the orphan and calls wait() when it finishes.
Q: How are zombies cleaned up? A: The parent must call wait() to read the exit status. If the parent exits, init adopts and cleans up the zombie.
Q: Can you kill a zombie with 'kill -9'? A: No. A zombie is already dead, it has no running code to receive a signal. Only the parent calling wait() removes it.
